# consultantmaxxing

An AI strategy/management consultant. Give it a business problem; it scopes it,
builds an issue tree, researches the real world with sourced facts, runs the numbers
in code, red-teams its own conclusions, and delivers an executive memo, slide
storyline, model spreadsheet and sources appendix.

Status: under construction. See [PLAN.md](PLAN.md) for the design and
[PROGRESS.md](PROGRESS.md) for where the build is.

## Setup (will be finalised in Phase 8)

1. Copy `.env.example` to `.env` and add a Groq API key.
2. Optionally install [Ollama](https://ollama.com) for local models.
3. Place the private source PDFs in `data/private/` (not included in this repo).
